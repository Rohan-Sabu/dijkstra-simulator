# Dijkstra Simulator 🚀

### Learn. Visualize. Practice. Master.

An interactive learning platform that brings **Dijkstra's Shortest Path Algorithm** to life through visual simulations, hands-on experiments and quizzes.


## ✨ What Can You Do?

- 📚 **Learn** – Understand graph theory, routing and Dijkstra's algorithm through interactive lessons.
- 🌐 **Build Networks** – Create your own network by connecting routers with different link costs.
- ⚡ **Visualize** – Watch Dijkstra's algorithm find the shortest paths, step by step.
- 🎯 **Practice** – Solve shortest-path exercise and test your understanding.
- 🧠 **Take Quizzes** – Challenge yourself with interactive questions.
- 📖 **Explore** – Access formulas, pseudocode, key concepts and viva questions.
  

## 🛠️ Built With

- Java
- Java Swing & AWT
- Dijkstra's Shortest-Path Algorithm

**No external libraries required.**


## ⚙️ Prerequisites
- Java (JDK 8 or later; JDK 17+ works seamlessly)


## ▶️ Get Started
From the project/source root, compile and execute it in the terminal:

```bash
javac DijkstraSimulator.java
java DijkstraSimulator
```


**Explore networks. Understand algorithms. Find the shortest path.**
